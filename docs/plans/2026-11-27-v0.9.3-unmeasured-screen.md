# 0.9.3 — 모델 판정을 못 했는데 "0%·기억이 먹히고 있음"으로 보이던 것 (2026-11-27)

0.9.2 를 맥에 올리고 원격 접속(SSH)으로 `forgen audit baseline --freeze` 를 돌리다 찾았다. SSH 세션에서는 macOS 키체인이 잠겨 claude CLI 가 로그인 정보를 못 읽어 모델 판정이 전부 실패했다. 고정은 올바르게 거부했지만 화면이 틀린 말을 했다. 새 기능 없음.

|---|---|---|
| 1 | 판정 0개인데 "같은 말을 다시 하는 일이 적다(기억이 먹히고 있음)"·표의 0%·오차 범위 0%~0% | 판정을 대부분 못 한 회차는 숫자 없이 "같은 말 다시 하기: 재지 못함 — 까닭". 감사 첫 화면·`audit recurrence`·`baseline`·`--share`·`fix --report` 모두 |

| 3 | 부딪힘·중복·섞임도 판정 0개인데 "0쌍·0묶음·0개 (모델 판정, 일부 못 함)" | 후보 절반 넘게 못 했으면 "재지 못함 — 까닭", 일부만 못 했으면 "후보 N개 중 M개 못 함 — 실제는 더 있을 수 있음". 자세히 페이지 탭도 "판정 못 함" |

## 검증
- 맥 실데이터 복사본(임시 HOME)에 이 빌드를 깔고 SSH 로 실제 실패 상황을 재현해 `audit recurrence`·`audit`·`audit --share`·`fix --report`·`audit baseline --freeze` 출력 전문을 읽음.
- 서버 실데이터(정상 판정)의 첫 화면이 바뀌지 않음.
- build·전체 vitest·lint·self-gate.
