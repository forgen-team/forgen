## 검증 순서
1. 구현(새 기능 금지, 위 10개만).
2. 실데이터 복사본에서 사용자 흐름 전체: `forgen audit` → `fix --list` → `fix <id>` → `--apply` → `fix --report` → `--undo` → `audit recurrence` → 세션 시작 블록. 출력 전문을 파일로 남긴다.
3. fresh-context 비평 2개: (a) 코드·데이터 안전 (b) **실제 출력 전문을 주고 "처음 보는 사람이 이해하나, 쓸모 있나, 숫자가 정직한가"**.
4. 리드가 직접 출력을 사용자 입장에서 읽고 10개 완료 조건을 하나씩 대조.
5. 오너에게 실제 화면(쉬운 말 한 페이지)을 보여 확인받은 뒤에만 0.9.1 배포.

## 구현 기록 (fix/v0.9.1)
- #7 지시문 판별(`src/audit/checks.ts` isDirective): forgen 룰·교정 메모 파일은 언제나 지시. 마크다운 줄은 표 줄·제목·파일 목록 줄(`x.skill.md` - 설명)을 빼고, 명령형·금지·규칙 어미/낱말(하라·말 것·금지·필수·반드시·항상·한다·는다 … / must·never·always·don't·영어 명령문 동사)이 있을 때만 지시. 실데이터 표본 20줄 손 확인: 1차 규칙 17/20 → 고친 규칙 19/20(남은 1건은 "…필수 사항" 소제목 줄). 표본 원문은 오너 기억 내용이라 저장소에 싣지 않는다.
- #2 세션 수 = 최근 30일 대화 기록의 메시지 cwd(가장 깊은 감사 폴더 하나). 세션 시작 폴더 이름만 보면 홈에서 시작해 프로젝트로 들어가 일하는 세션이 전부 홈으로 잡혔다.
- #11 `--no-model` 이면 실행 전후 `~/.claude` 해시가 같다. 모델 판정을 켜면 forgen 이 부르는 `claude` CLI 가 자기 상태 파일(`~/.claude/backups/`·`plugins/store/`)을 쓴다 — forgen 이 쓰는 것은 없고, 첫 실행 안내에 적었다(`tests/e2e/matrix/t24.sh`).
- #1 극단값: 중요 지침을 40자 짧은 형태로 줄여도 세션 시작 글자 상한(호스트가 통째로 버리는 ~9,500자 전체의 forgen 몫 7,000자)을 넘으면, 우선순위가 가장 낮은 중요 지침부터 뺀다. 그 경우 블록의 Omitted 줄에 "중요 지침 N개는 이번 세션에 안 넣음(자리 부족)"으로 적는다. 실데이터 5폴더에서는 일어나지 않는다(빠진 중요 지침 0).
- 비평 반영(A1): 같은 뜻 중복은 지시문만 보되, 부딪힘은 지시문 + 사실 진술(isFactualClaim: 지금 구성·상태를 설명하는 문장)까지 본다 — 설명문과 옛 구조를 설명하는 룰의 어긋남(낡은 사실)을 놓치지 않게.

## 판정기 검사 — 사전 등록(2026-11-26, 결과를 보기 전에 적음)
오너 결정: 독립 채점과의 일치율 90% 를 넘길 때까지 고친다. 오너 검수 대신 독립 모델(Opus) 블라인드 채점 + 리드 판정.
- **측정 대상 질문은 하나**: "이 교정이 고치려는 행동을, 이 기억이 **교정 시점에 이미** 지시하고 있었나" (N4 의 '적혀 있는데도 또 말함' 판정). 교정 **뒤에** 생긴 기억과의 짝("그 뒤 기억이 됐나")은 다른 질문이라 이 측정에서 빼고, 코드에서도 그 짝은 이 질문으로 판정하지 않는다(따로 셈).
- **표본**: 실데이터 복사본의 재생 결과에서 이 질문으로 판정된 쌍만, 새 시드(20261126)로 25쌍 — 판정기 yes 10 · no 10(사전 필터 점수 상위) · 모름 5. 지난 25쌍은 문구 조정에 썼으므로 쓰지 않는다(겹치면 다시 뽑음).
- **채점**: Opus 블라인드(판정기 답을 안 봄), 같은 지침 문서. 일치율 = 판정기 yes/no 와 Opus yes/no 가 같은 쌍 / 판정기 yes·no 쌍(모름·Opus unsure 는 분모에서 뺌, 그 수는 따로 적음). 리드는 엇갈린 쌍만 원문을 읽고 판정 근거를 기록하되 **일치율 계산은 바꾸지 않는다**.
- **합격**: 일치율 ≥ 90% 이고 분모 ≥ 18. 미달이면 원인을 기록하고 다시 고친 뒤 **또 새 표본**으로 잰다.
