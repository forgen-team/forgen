## 4. 결함 목록

### 치명: 규칙이 사라지거나 주입되지 않는다
- **R1 무관한 교정이 룰을 죽인다.** 축 일치 + 토큰 1개면 전이. 실제 9건 중 8건 오탐. 한국어 룰은 드리블 교정의 "사용자" 토큰으로 retire. `trigger-t1-correction.ts` [실측]
- **R2/E1 렌더 절단.** `perRuleFile` 3000자 상한으로 파일이 `- [qua`에서 끊긴다. 룰 3개와 `correction-record` 지시가 빠진다. 생존은 UUID 순서, `inject_count`는 잘린 룰도 증가. [직접]
- **R3 렌더가 래퍼 실행에서만 갱신.** `claude` 직접 실행이면 교정이 파일에 반영되지 않는다. 호출부는 `harness.ts:399`, `config-injector.ts:467`뿐 [직접]. 이 저장소 프로젝트 파일이 10-06에 멈춘 원인이고, 해제된 Fable 지시가 지금도 주입된다.
- **R7 채굴 룰 영구 삭제.** TTL 21일 + 보관 7일. 누적 1,352개 삭제. 11-05에 6개 추가 삭제 예정(`rule-store.ts:297`). **백업 완료:** `~/forgen-backup-2026-11-04/`
- **교정 전수 추적.** 271건 중 활성 26, 사라짐 245(strong 3, 명시 default 20, 채굴 222). 명시 복구 후보 22건. "271"의 232건은 Haiku 채굴이고 사용자 직접 기록은 39건. `audit/reports/rules.md`

### 치명: 추출이 실제 대화를 보지 않는다
- **C2/D3 입력.** 123MB 세션에서 실제 유저 메시지 1,419개 중 2개, 파일의 0.1%만 요약에 든다. 추출된 3개는 첫 `/goal` 프롬프트를 베꼈다. 61개 세션의 요약 중앙값 155자이고, 200자 미만이면 로그 없이 종료 [실측, 직접]
- **D4 타임아웃.** 재현됨 [직접], 원인 [미확인]. 도구 사용, 파이프 점유, Node 20은 배제.

### 치명: 진단이 거짓말한다
- **F-01** doctor가 settings의 hook·MCP·statusline을 점검하지 않는다. 12개를 동시에 부숴도 무관한 2건만 말하고 exit 0.
- **F-02** `config hooks`는 항상 `23/23 active`.
- **F-03** 읽기 실패를 `No rules.`, `No blocks recorded`로 표시. 또는 출력 0바이트에 exit 1.

### 높음: 강제가 약속대로 안 된다
- **H1** secret-filter·slop-detector는 사용자 화면 경고만. 모델에 전달되지 않고 차단도 못 한다.
- **H2/R12** `rm -rf`는 절대경로만 차단. `rm -rf build`, `-r -f`, `-fr`, `bash -c` 통과 [직접]. `find -delete`, `shutil.rmtree`, `.env` 커밋도 통과.
- **H3** secret-filter가 Bash 출력 객체를 `[object Object]`로 문자열화해 비밀을 놓친다(`secret-filter.js:79`).
- **H4/R4 의미 룰 판정.** 판정 48건 중 correct 7, 오탐 31, unsure 10. 합성 위반 7건 차단 0, 무관한 완료 보고 3건을 Deadeye 룰이 차단. 이 조사 중에도 2회 실제 발생. strong 2개가 이 오탐으로 강등됨.
- **R5** 활성 18개 중 8개는 아무 강제도 없다. "구현 먼저 금지"는 탐지 불가인데 위반 0을 근거로 승급.
- **R8** 프로필 4축은 표시 전용. 값을 바꿔도 렌더가 같다.
- **R11/E2** 룰에 프로젝트 범위가 없어 Deadeye 룰이 모든 프로젝트에 적용된다. 활성 20개 중 9개가 프로젝트 전용으로 보인다.
- **C1 hook 이중 출력.** `solution-injector`가 `pre-tool-use`를 import하며 `main()`이 재실행돼 stdout에 JSON 2개 [직접]. 3회 연속이면 deny까지 나온다 [실측]. Claude Code가 어떻게 처리하는지 [미확인].

### 높음: 환경 의존
- **I-H1** hook·MCP가 설치 시점 버전 경로에 고정. Node 삭제 또는 PATH에 node 없음이면 전부 끊긴다.

- **I-M3** agents가 전역으로 공급되지 않는다.
- **H5/F-11** cwd 기준 경로가 `FORGEN_HOME`을 무시한다. `~/.compound→~/.forgen`이면 프로젝트와 전역이 섞인다. 이 조사 중 실제 오염 발생.
- **플러그인** `failed to load` [실측, Mac 포함].

### 높음: 확장 목표를 막는 것
- **E2** 호스트 중립 원본 없음. 룰 JSON의 26%가 Claude 전용 필드. 정책 본문은 자연어라 이식 가능.

- **E5** parity는 손으로 쓴 값이고 동등성을 재지 않는다.
- **E8, B** live e2e는 기본 skip. 결함이 테스트를 통과한 이유는 mock보다 약속을 재지 않아서다(버그 동작을 픽스처로 고정).
